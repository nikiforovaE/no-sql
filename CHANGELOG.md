# Changelog

Все значимые изменения в этом проекте будут документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.7.0] - 2026-05-30

### Добавлено

- Реализация лабораторной 7 (Рекомендации мероприятий с использованием Neo4j)
- Эндпоинт `GET /recommendations` — персональные рекомендации на основе схожих лайков других пользователей
- Синхронизация сущностей (User, Event, LIKED) в Neo4j через новый сервис `Neo4jSyncService`
- Кэширование рекомендаций в Redis (`user:{user_id}:recomms`) по принципу Cache-Aside
- Алгоритм дедупликации событий с одинаковым названием по времени начала и сортировка по весу рекомендации
- Контейнер `neo4j` в `docker-compose.yml` и зависимость Neo4j в `pom.xml`

### Изменено

- Триггерная отправка данных в граф при сохранении пользователей, событий и лайков
- Параметры подключения к Neo4j в конфигурации

## [1.6.0] - 2026-05-16

### Добавлено

- Реализация лабораторной 6 (Отзывы на Cassandra и Redis)
- Новые эндпоинты:
    - `POST /events/{id}/reviews` — оставить отзыв
    - `GET /events/{id}/reviews` — список отзывов с пагинацией
    - `PATCH /events/{id}/reviews/{review_id}` — редактирование отзыва
- Хранение текстов отзывов в Cassandra (`event_reviews`)
- Кэширование агрегированного рейтинга и количества отзывов в Redis

### Изменено

- Доработан `GET /events`: поддержка `include=reviews` и возможность передачи нескольких значений через запятую в
  `include`

## [1.5.0] - 2026-05-02

### Добавлено

- Реализация лабораторной 5 (Реакции на Cassandra и Redis)
- Новые эндпоинты:
    - `POST /events/{id}/like` — поставить лайк
    - `POST /events/{id}/dislike` — поставить дизлайк
- Интеграция с Apache Cassandra для хранения реакций
- Кэширование счетчиков лайков в Redis (паттерн Cache-Aside) по MD5-хэшу названия

### Изменено

- Доработан `GET /events`: добавлен параметр `include=reactions` для отображения счетчиков

## [1.4.0] - 2026-04-10

### Добавлено

- Реализация лабораторной 4 (Шардирование и репликация)
- Новые эндпоинты:
    - `PATCH /events/{id}` — редактирование мероприятия
    - `GET /events/{id}` — детальная карточка мероприятия
    - `GET /users` — поиск организаторов
    - `GET /users/{id}` — карточка организатора
    - `GET /users/{id}/events` — мероприятия конкретного организатора
- Шардирование коллекции `events` в MongoDB по хэш-ключу `created_by`
- Настройка репликации MongoDB (Replica Set: 1 Primary, 2 Secondary)

### Изменено

- Расширены фильтры `GET /events` (категория, город, цена, даты)

## [1.3.0] - 2026-03-28

### Добавлено

- Реализация лабораторной 3 (Пользователи и события на MongoDB)
- Новые эндпоинты:
    - `POST /users` — регистрация пользователя
    - `POST /auth/login` — аутентификация
    - `POST /auth/logout` — выход из аккаунта
    - `POST /events` — создание события
    - `GET /events` — просмотр событий с фильтрацией
- Интеграция с MongoDB (коллекции `users` и `events`)
- Хеширование паролей алгоритмом BCrypt
- Индексы для коллекций в MongoDB (уникальный `username`, `title` и др.)

### Изменено

- Обновлена структура сессии в Redis: добавлена привязка к `user_id`
- Добавлен сервис `mongodb` в `docker-compose.yml`

## [1.2.0] - 2026-03-14

### Добавлено

- Реализация лабораторной 2 (Анонимные сессии на Redis)
- Новый эндпоинт `POST /session` для создания и продления анонимных сессий
- Интеграция с Redis для хранения пользовательских сессий в виде хэш-таблиц
- Добавлена коллекция запросов Postman в папку `api/`
- Добавлен сервис `redis` в `docker-compose.yml`

### Изменено

  в БД
- Обновлен `pom.xml`: добавлены зависимости `spring-boot-starter-data-redis`, `spring-boot-configuration-processor`,
  `lombok`
- В `.env.local` добавлены настройки подключения к Redis

## [1.0.0] - 2026-02-06

Первая версия шаблона проекта
для выполнения лабораторных работ по курсу NoSQL баз данных (см. [ndbx](https://github.com/sitnikovik/ndbx))

### Добавлено

- *.env.local*: файл для хранения конфигурации проекта
- *.gitignore*: файл для указания игнорируемых файлов и папок (для популярных языков программирования)
- *.labrc*: файл для указания текущей лабораторной работы
- *CHANGELOG.md*: файл для ведения истории изменений проекта
- *CODEOWNERS*: файл для указания ответственных за различные части проекта
- *CONTRIBUTING.md*: руководство для разработчиков по внесению изменений в проект
- *Makefile*: файл для автоматизации запуска и остановки проекта
- *README.md*: файл с описанием проекта, его целей и инструкциями по использованию
- *.github/workflows/: воркфлоу для автоматической проверки лабораторных работ в GitHub Actions
- *eventhub.yml*: проверка лабораторных работ по проекту EventHub
- *.github/scripts/*: папка для хранения скриптов, используемых в воркфлоу GitHub Actions
- *lab_number.sh*: скрипт для получения номера текущей лабораторной работы из файла *.labrc*
